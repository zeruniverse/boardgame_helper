## 游戏概述

德州扑克是一款经典的社区牌扑克游戏，本系统支持以下特性：

- **支持人数**：2–10 人
- **发牌模式**：
  - **系统发牌**：系统自动洗牌、发牌，玩家在线上进行完整对局
  - **线下发牌**：系统仅控制游戏流程和筹码统计，不发实体牌（玩家线下使用实体扑克牌进行游戏，系统负责流程推进和筹码结算）

## 游戏流程

一局游戏的完整流程如下：

### 1. 准备阶段
所有仍持有筹码的玩家自动参与本局游戏。筹码为 0 的玩家自动跳过，需通过 **Take/TakeAll** 操作补充筹码后方可重新加入。

### 2. 盲注（Blinds）
- 系统标记 **Dealer（庄家）** 位置
- Dealer 的左侧玩家强制下注 **小盲注（Small Blind, SB）**
- 小盲注玩家的左侧玩家强制下注 **大盲注（Big Blind, BB）**
- 盲注金额由房间配置决定

> 若房间内仅剩 2 名玩家，则 Dealer 兼做小盲注，另一位玩家做大盲注。

### 3. 发手牌（Hole Cards）
每位玩家获得 **2 张私有牌**，仅自己可见（线下模式中由玩家自行发牌）。

### 4. 翻牌前下注（Pre-flop）
- 从大盲注玩家的左侧开始，按顺时针方向依次行动
- 每位玩家可选择：跟注（Call）、加注（Raise）、弃牌（Fold）、或全下（All-in）
- 此轮下注结束后，进入翻牌阶段

### 5. 翻牌（Flop）
- 发出 **3 张公共牌**，放置于桌面中央，所有玩家共享
- 开始第二轮下注，由小盲注玩家（或最早未弃牌玩家）先行动
- 本轮可选择：过牌（Check）、下注（Bet）、跟注（Call）、加注（Raise）、弃牌（Fold）、全下（All-in）

### 6. 转牌（Turn）
- 发出第 **4 张公共牌**
- 开始第三轮下注，行动规则同翻牌轮

### 7. 河牌（River）
- 发出第 **5 张公共牌**（最后一张公共牌）
- 开始第四轮（最后一轮）下注

### 8. 摊牌比牌（Showdown）
- 四轮下注结束后，剩余未弃牌的玩家进入摊牌阶段
- 每位玩家从自己的 **2 张手牌 + 5 张公共牌** 中选出最佳的 **5 张牌组合**
- 按比牌规则比较大小，决定胜负
- 分配底池筹码给获胜者

### 9. 轮换 Dealer
- 本局结束后，Dealer 位置顺时针移动一位
- 开始下一局游戏

## 玩家操作

在不同下注轮次中，玩家可执行以下操作：

| 操作 | 说明 | 适用场景 |
|------|------|----------|
| **Check（过牌）** | 不下注，将行动权传递给下一位玩家 | 当前已下注额等于本轮最高下注额时 |
| **Call（跟注）** | 投入筹码，使自己的下注额等于当前最高下注额 | 当前下注额低于本轮最高下注额时 |
| **Raise（加注）** | 投入比当前最高下注额更多的筹码，提高下注门槛 | 筹码足够且房间允许加注时 |
| **Fold（弃牌）** | 放弃本局，已下注筹码归入底池 | 任何时候 |
| **All-in（全下）** | 将所有剩余筹码一次性投入 | 筹码不足跟注/加注时自动触发，或玩家主动选择 |
| **Take/TakeAll** | 游戏结束后取回筹码（补充筹码） | 游戏结束阶段，筹码为 0 时 |

### 操作优先级说明
- 若玩家筹码不足以完成 **Call**，系统将自动将操作转为 **All-in Call**
- 若所有未弃牌玩家都已 **All-in**，系统将自动推进至摊牌阶段
- 若某一轮下注后仅剩一名未 **Fold** 的玩家，该玩家直接获胜，无需继续发牌

## 比牌规则

### 牌型大小排序（从大到小）

| 排名 | 牌型 | 说明 |
|:----:|------|------|
| 1 | **皇家同花顺** | 同花色的 10-J-Q-K-A |
| 2 | **同花顺** | 同花色且连续的 5 张牌 |
| 3 | **四条** | 四张相同点数的牌 |
| 4 | **葫芦** | 三条 + 一对 |
| 5 | **同花** | 同花色的 5 张牌（不连续） |
| 6 | **顺子** | 连续点数的 5 张牌（不同花色） |
| 7 | **三条** | 三张相同点数的牌 |
| 8 | **两对** | 两个不同的对子 |
| 9 | **一对** | 两张相同点数的牌 |
| 10 | **高牌** | 无任何以上牌型，比较单张最大牌 |

### 平局判定规则

1. **同牌型比较最大牌点**：例如两条顺子比较时，最大牌点数高者获胜
2. **A 的特殊处理**：A 可作为 **14（最大，即 10-J-Q-K-A）** 或 **1（最小，即 A-2-3-4-5）**
3. **完全平局均分底池**：若牌型及所有关键牌点完全相同，则相关玩家均分底池

## 边池（Side Pot）

当玩家进行 **All-in** 时，可能触发边池机制：

### 核心规则
- **All-in 玩家** 只能赢取自己实际参与下注的那部分底池
- 超出 All-in 玩家下注额的多余筹码，形成 **边池（Side Pot）**
- 边池由其他下注更多的玩家竞争

### 示例
假设三名玩家下注情况如下：

| 玩家 | 下注总额 |
|------|----------|
| 玩家 A | 100（All-in）|
| 玩家 B | 300（All-in）|
| 玩家 C | 500 |

- **主池**：100 × 3 = 300，由 A、B、C 三人竞争
- **边池 1**：(300 - 100) × 2 = 400，由 B、C 两人竞争
- **边池 2**：(500 - 300) × 1 = 200，仅由 C 赢取（若 C 获胜）

## 房间配置参数

创建房间时可配置以下参数：

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `allowSystemDealing` | 布尔值 | 是否启用系统发牌模式。`true` 为系统发牌，`false` 为线下发牌 | `true` |
| `blinds.smallBlind` | 整数 | 小盲注金额 | `5` |
| `blinds.bigBlind` | 整数 | 大盲注金额（通常为小盲的 2 倍） | `10` |
| `defaultStack` | 整数 | 每位玩家的默认初始筹码数量 | `1000` |

### 配置示例

```json
{
  "allowSystemDealing": true,
  "blinds": {
    "smallBlind": 5,
    "bigBlind": 10
  },
  "defaultStack": 1000
}
```

## 后端逻辑说明

### 状态管理
- **Worker** 负责管理完整的游戏状态，包括：
  - 牌组（Deck）：标准 52 张扑克牌
  - 公共牌（Community Cards）：已发出的 3-5 张公共牌
  - 底池（Pot）：当前总下注额及边池分配
  - 下注额（Bets）：每位玩家本轮已下注金额
  - 当前回合（Current Round）：Pre-flop / Flop / Turn / River / Showdown
  - 行动顺序（Action Order）：当前轮到哪位玩家

### 关键逻辑

#### 回合结束判定
每轮下注结束时，系统检查以下终止条件：
- 若仅剩 **一名未 Fold 玩家**，该玩家直接获胜，立即分配底池
- 若所有未 Fold 玩家都已 **All-in**，自动推进至摊牌阶段

#### All-in 处理
- All-in 玩家的下注额被锁定，不再参与后续下注轮次的决策
- 系统自动计算并创建边池（Side Pot）
- All-in 玩家自动视为已行动，不会阻塞下注轮次的推进

#### 超时处理
- 玩家若在限定时间内未做出操作，系统自动执行 **Fold**
- 超时时间由系统统一配置

#### 摊牌比牌
- 从剩余玩家的 2 张手牌 + 5 张公共牌中，枚举所有 C(7,5)=21 种 5 张牌组合
- 选出每位玩家最大的牌型进行比较
- 根据比牌规则分配主池及各边池

## 前端界面说明

### 显示内容
- **社区牌区域**：显示已发出的 3-5 张公共牌
- **玩家手牌**：系统发牌模式下显示自己的 2 张私有牌；线下发牌模式下不显示
- **当前下注额**：显示每位玩家本轮已下注金额及当前总底池
- **玩家状态**：显示当前轮到哪位玩家行动、已 Fold/All-in 状态标识
- **Dealer 标记**：标明当前 Dealer 位置

### 操作栏
操作栏根据当前游戏状态和玩家筹码动态显示可用操作：

| 状态 | 显示操作 |
|------|----------|
| 无需追加筹码 | Check / Raise / Fold |
| 需要追加筹码 | Call / Raise / Fold |
| 筹码不足跟注 | All-in Call / Fold |
| 只剩一名对手且对方 All-in | Call（All-in）/ Fold |

### 特殊提示
- 当玩家筹码不足以完成 **Call** 时，**Call** 按钮自动变为 **All-in Call**
- 加注按钮旁显示当前最小加注额和玩家最大可加注额
- 游戏结束后显示结算面板，提供 **Take/TakeAll** 按钮补充筹码

## 快速参考

### 一局流程速览
```
准备 → 盲注 → 发手牌(2张) → Pre-flop下注 → Flop(3张) → 下注 → Turn(1张) → 下注 → River(1张) → 下注 → 摊牌比牌 → 轮换Dealer
```

### 玩家决策速查
- **不想下注且无人下注** → Check
- **想匹配他人下注** → Call
- **想加大赌注** → Raise
- **牌不好想放弃** → Fold
- **筹码不够或想搏一把** → All-in
