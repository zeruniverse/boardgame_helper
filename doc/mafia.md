## 1. 游戏概述

杀人游戏（又称黑手党 / Mafia）是一款经典的社交推理桌游。本系统支持 **6~20 人** 同时参与，由系统自动分配角色并全程控制游戏进程与夜间行动。

游戏将玩家划分为**好人阵营（蓝方）**与**杀手阵营（红方）**，双方通过白天的发言讨论与投票、夜晚的特殊技能对抗，展开一场推理与欺骗的较量。

### 核心特点

- **全自动流程**：系统负责角色分配、阶段切换、计时与超时处理
- **身份隐藏**：玩家初始只知道自己的角色，需通过言行推理他人身份
- **昼夜交替**：白天讨论投票，夜晚技能交锋，循环往复直到分出胜负

## 2. 角色系统

游戏共设有 5 种角色，分属两个对立阵营：

### 2.1 杀手（Killer）— 红方

| 项目 | 说明 |
|------|------|
| **阵营** | 杀手阵营（红方） |
| **技能** | 夜晚可与其他杀手共同选择一名玩家将其杀死 |
| **行动方式** | 多名杀手需共同商议并达成一致目标 |
| **胜利条件** | 屠边：警察全部死亡，或除警察外的好人阵营全部死亡 |

> 杀手是游戏的核心反派角色，白天伪装成好人参与讨论，夜晚暗中杀人。

### 2.2 警察（Cop）— 蓝方

| 项目 | 说明 |
|------|------|
| **阵营** | 好人阵营（蓝方） |
| **技能** | 夜晚可查验一名玩家是否为杀手 |
| **查验结果** | 系统仅告知被查验者是否为杀手（不告知具体角色） |
| **配合策略** | 可通过白天的发言隐晦地向好人传递查验信息 |

> 警察是好人阵营的信息核心，正确查验并合理传递信息是赢得游戏的关键。

### 2.3 医生（Doctor）— 蓝方

| 项目 | 说明 |
|------|------|
| **阵营** | 好人阵营（蓝方） |
| **技能** | 夜晚可选择一名玩家进行救治，使其免于当晚死亡；也可主动选择本夜不救治 |
| **可自救** | 可以救治自己 |
| **限制** | **不可连续两晚救治同一名玩家**（包括自己） |

> 医生是好人阵营的守护者，合理判断保护对象可以挽救关键角色。

### 2.4 狙击手（Sniper）— 蓝方

| 项目 | 说明 |
|------|------|
| **阵营** | 好人阵营（蓝方） |
| **技能** | 拥有**一次**狙击机会，夜晚可狙击一名玩家 |
| **特殊机制** | 狙击**无视医生的保护**，必定命中 |
| **风险** | 狙击到好人（蓝方）会造成巨大损失，需谨慎使用 |

> 狙击手是一把双刃剑，仅有一次机会且无视保护，需要极高的判断力。

### 2.5 平民（Civilian）— 蓝方

| 项目 | 说明 |
|------|------|
| **阵营** | 好人阵营（蓝方） |
| **技能** | 无特殊能力 |
| **作用** | 白天参与讨论和投票，依靠推理能力帮助好人阵营 |

> 平民虽然没有特殊技能，但在投票环节与讨论中同样至关重要。

### 角色阵营一览

```
蓝方（好人阵营）: 警察 + 医生 + 狙击手 + 平民
红方（杀手阵营）: 杀手
```

## 4. 游戏流程

游戏由系统自动驱动，完整的游戏流程如下：

```
准备阶段 → 第一天白天 → [夜晚 → 白天] 循环 → 游戏结束
```

### 4.1 准备阶段

1. 房间内所有**在线玩家**准备就绪；离线保留席位不参与本局，也不阻塞开局
2. 系统按当前在线参与人数（6~20 人）生成/校验角色配置并分配角色（玩家仅知道自己的角色）
3. 系统宣布游戏开始

### 4.2 第一天白天

第一天白天为特殊的起始阶段，流程如下：

| 步骤 | 说明 |
|:----:|------|
| 1 | **所有人睁眼**：系统提示所有玩家睁眼 |
| 2 | **自由讨论**：所有存活玩家进行自由发言讨论（第一轮不可自投） |
| 3 | **投票处决**：玩家投票选出一名被处决者 |
| 4 | **公布结果**：被处决者出局（有遗言，详见遗言机制） |

> 第一天是信息最少的阶段，玩家需要通过初步发言寻找矛盾点。

### 4.3 夜晚阶段

夜晚阶段只有**特殊角色**（杀手、警察、医生、狙击手）需要进行操作。

各角色在本系统中**并行行动**（同时被唤醒，各自独立操作），行动结果在夜晚结束时统一结算：

```
┌─────────────────────────────────────────────────────────┐
│                      夜 晚 流 程                          │
├─────────────────────────────────────────────────────────┤
│  杀手行动 → 共同选择一名目标将其杀死                      │
│  警察行动 → 各自独立选择一名玩家查验其身份                 │
│  医生行动 → 各自独立选择救治一名玩家，或主动放弃本夜救治     │
│  狙击行动 → 狙击手选择一名目标进行狙击（仅一次）           │
│  （所有角色完成行动后，系统统一结算夜晚结果）              │
└─────────────────────────────────────────────────────────┘
```

#### 夜晚行动说明

| 角色 | 行动内容 | 备注 |
|:----:|----------|------|
| 杀手 | 所有杀手共同商议，选择一名目标将其杀死 | 多名杀手需**达成一致目标**才执行 |
| 警察 | 每名警察独立选择一名玩家进行查验 | 系统分别告知查验结果 |
| 医生 | 每名医生独立选择一名玩家进行救治，或主动跳过 | 被救治者免于当晚死亡；**不可连续两晚救同一人**；跳过不会产生救治记录 |
| 狙击手 | 选择一名目标进行狙击（整局仅一次） | 狙击**无视医生保护**，必定命中 |

### 4.4 白天阶段（第2天起）

夜晚结束后进入白天，流程如下：

| 步骤 | 说明 |
|:----:|------|
| 1 | **公布死亡信息**：系统宣布当晚的死亡情况 |
| 2 | **遗言阶段**：有遗言轮数的出局玩家发表遗言 |
| 3 | **自由讨论**：所有存活玩家进行自由发言讨论 |
| 4 | **投票处决**：玩家投票选出一名被处决者 |
| 5 | **公布结果**：被处决者出局（若有遗言轮数可发表遗言） |

### 4.5 循环与结束

- 夜晚 → 白天的循环持续进行
- 每轮循环结束后系统检查胜负条件
- 满足任一胜利条件时游戏立即结束并公布结果

### 完整流程图示

```
     ┌──────────────┐
     │   准备阶段    │ ← 系统分配角色
     └──────┬───────┘
            ▼
     ┌──────────────┐
     │  第一天白天   │ ← 所有人睁眼、讨论、投票（不可自投）
     └──────┬───────┘
            ▼
   ┌────────────────┐     Yes
   │  是否满足结束条件? │ ─────────→ 游戏结束，公布结果
   └──────┬─────────┘
          │ No
          ▼
     ┌──────────────┐
     │   夜晚阶段    │ ← 杀手、警察、医生并行行动
     └──────┬───────┘
            ▼
     ┌──────────────┐
     │   白天阶段    │ ← 公布死亡、遗言、讨论、投票
     └──────┬───────┘
            │
            └────────→ 回到 "是否满足结束条件?" 检查
```

## 5. 胜负判定

游戏在任何时刻满足以下任一条件时立即结束：

### 5.1 好人阵营（蓝方）胜利

> **所有杀手死亡**

当场上剩余的杀手数量降为 0 时，好人阵营获胜。

### 5.2 杀手阵营（红方）胜利

> **警察全部出局，或平民阵营全部出局**

当场上所有警察死亡，或所有非警察的好人角色（医生、狙击手、平民）死亡时，杀手阵营获胜。

### 判定时机

系统在以下时刻进行胜负判定：

- 每次白天投票处决后
- 每个夜晚结算完成后
- 一旦满足任一条件，游戏**立即结束**

### 胜负速查

| 场景 | 结果 |
|------|------|
| 杀手数量 = 0 | **蓝方胜利** |
| 警察全部死亡 | **红方胜利** |
| 医生、狙击手、平民等平民阵营角色全部死亡 | **红方胜利** |
| 例如：2杀手 vs 1警察1平民 | 游戏继续（警察和平民阵营均未全灭） |

## 6. 配置参数

游戏支持以下可配置参数，管理员可在创建房间时进行设置：

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|:------:|------|
| `speakTime` | Number / null | `null` | **发言时间**（秒）。玩家白天自由讨论的时间限制。`0` 或 `null` 表示不限时 |
| `actionTime` | Number / null | `null` | **投票时间**（秒）。白天普通投票与 PK 投票的时间限制。`0` 或 `null` 表示不限时 |
| `nightTime` | Number / null | `null` | **夜晚总时间**（秒）。整个夜晚阶段的总时长。`0` 或 `null` 表示不限时 |
| `lastWordRound` | Number | `3` | **遗言轮数**。被处决的玩家从被处决时开始，前 `N` 轮拥有遗言权。默认前 3 轮被处决者有遗言 |

### 配置示例

```json
{
  "speakTime": 120,
  "actionTime": 30,
  "nightTime": 120,
  "lastWordRound": 3
}
```

> 上述配置表示：发言限时 2 分钟，白天/PK 投票限时 30 秒，夜晚总限时 2 分钟，前 3 轮被处决者有遗言。

## 7. 特殊机制

### 7.1 平安夜

**定义**：夜晚没有任何玩家死亡的情况。

平安夜可能由以下原因导致：

- 杀手**未选择杀人目标**（放弃行动或超时未操作）
- 医生**成功救活**了被杀手选中的目标

> 平安夜的出现会让白天讨论更加激烈——是因为杀手没行动，还是医生救对了人？

### 7.2 医生限制

医生救治存在以下限制：

- **可自救**：医生可以选择救治自己
- **可主动空救**：医生可以直接选择本夜不救治，无需等待夜晚超时
- **不可连续两晚救同一人**：医生第 N 晚救治了某玩家，则第 N+1 晚不能再次救治该玩家（第 N+2 晚可以再次救治）
- 系统会阻止医生选择不符合规则的目标

### 7.3 狙击机制

狙击手拥有一项特殊的攻击能力：

- **无视保护**：狙击手的攻击**不受医生救治的影响**，被狙击的目标必定死亡
- **仅有一次机会**：狙击手在整个游戏中只能使用一次狙击机会
- **用后即消失**：使用狙击后，狙击手不再有特殊行动
- **阵营风险**：狙击手属于蓝方，若狙击到好人会造成蓝方损失

### 7.4 遗言机制

遗言是出局玩家在游戏中的最后发言机会：

- **默认前 3 轮有遗言**：`lastWordRound` 默认为 3，即前 3 轮被处决的玩家有遗言
- **遗言轮数计算**：从玩家被处决的轮次开始计算，不是从游戏开始
- **适用对象**：
  - 白天被**投票处决**的玩家
  - 夜晚被**杀手杀死**的玩家
- **无遗言**：超过 `lastWordRound` 轮次后，出局玩家无遗言

### 7.5 自投机制

- **第一轮不允许自投**：第一天白天的投票阶段，玩家不可投票给自己
- **之后轮次允许自投**：从第二天起，玩家可以选择投票给自己

### 7.6 超时处理

当配置了限时参数时：

- 玩家/角色在限定时间内未进行操作，系统视为**跳过/放弃**
- 杀手超时未选目标 → 当晚无人被杀（平安夜）
- 警察超时 → 放弃查验
- 医生超时 → 放弃救治
- 狙击手超时 → 放弃狙击机会（机会保留至后续回合）


### 7.7 断线与重连

- 白天阶段，离线且尚未完成的发言/投票会按阶段规则自动跳过，避免阻塞仍在线玩家。
- 夜晚阶段，**已经被 Worker 接受的行动不会因为随后断线而撤销**：警察已经完成的查验不能通过重连重复执行；医生已经提交的救治/跳过继续有效；杀手已经提交的目标仍参与杀手共识。
- 离线前**尚未提交**夜间行动的角色不会阻塞仍在线玩家；若该角色在本夜行动锁关闭后才重连，则本夜视为已经跳过。
- 多名杀手需要对所有已提交的选择达成一致。某名杀手提交异议后断线，不会把其意见自动删除；若全部杀手都离线且现有选择互相冲突，本夜按未形成杀人共识处理。
- 如果整局所有存活参与者都离线，当前流程会冻结，等待至少一名玩家重连后再继续，避免后台自动跨越多个阶段。

## 8. 后端逻辑说明

### 8.1 状态机设计

游戏采用**状态机（State Machine）**管理游戏阶段，主要状态包括：

| 状态 | 说明 |
|------|------|
| `SPEAK` | 自由讨论阶段，存活玩家可发言 |
| `VOTE` | 投票阶段，玩家投票选出处决目标 |
| `NIGHT` | 夜晚阶段，特殊角色依次行动 |
| `ACTION` | 角色行动阶段（杀手/警察/医生的具体操作） |
| `ENDED` | 游戏结束状态 |

状态之间的转换由系统根据游戏进程自动驱动。

### 8.2 夜晚行动管理

- 夜晚阶段，系统并行唤醒各特殊角色进行行动
- 只有拥有特殊技能的角色（杀手、警察、医生、狙击手）需要操作
- 平民玩家在夜晚阶段等待
- 各角色的操作结果由系统汇总，在白天阶段统一结算

### 8.3 超时自动处理

系统支持超时自动处理机制：

- 当配置了限时参数后，系统会在每个阶段启动倒计时
- 倒计时结束时，尚未操作的玩家视为放弃/跳过
- 超时处理逻辑：
  - 发言超时 → 自动结束发言阶段
  - 行动超时 → 该角色跳过本次行动
  - 投票超时 → 视为弃票

### 8.4 数据一致性

- 所有游戏状态变更通过状态机统一管理，确保流程的顺序执行
- 角色的技能效果在夜晚阶段结束后统一结算
- 胜负判定在每次状态转换的边界点进行
