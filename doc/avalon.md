# 阿瓦隆（Avalon）游戏规则

---

## 一、游戏概述

阿瓦隆是一款经典的多人社交推理桌游，由系统自动主持游戏流程。

| 项目 | 说明 |
|------|------|
| **游戏人数** | 5–12 人 |
| **阵营划分** | 善良阵营 vs. 邪恶阵营 |
| **主持人** | 系统（自动分配角色、控制流程） |
| **特殊机制** | 邪恶阵营拥有私有聊天频道，可秘密讨论策略 |

> **核心目标**：善良阵营需要成功完成 3 次任务；邪恶阵营需要通过任务失败、阻止组队或刺杀梅林来破坏好人计划。

---

## 二、角色系统

游戏开始时，系统根据玩家人数自动分配角色。每位玩家获得一个隐藏身份，身份决定你的阵营、视野与获胜条件。

### 2.1 善良阵营（好人）

善良阵营的目标是**成功完成 3 次任务**，并在游戏结束时**保护梅林不被刺客刺杀**。

| 角色 | 英文名 | 能力说明 |
|------|--------|----------|
| **梅林** | Merlin | 游戏开始时知道**所有邪恶玩家的身份**（但看不到莫德雷德）。拥有最强信息优势，但必须隐藏自己，避免被刺客发现。 |
| **派西维尔** | Percival | 游戏开始时知道**梅林和莫甘娜的所在**，但系统不会标明谁是谁，只能看到两名玩家标记为"梅林/莫甘娜"。需要通过观察判断谁是真正的梅林。 |
| **忠诚的仆人** | Servant | 普通好人，没有任何额外信息。通过观察发言和投票来推理谁是队友。 |

### 2.2 邪恶阵营（坏人）

邪恶阵营的目标有三种胜利途径：
1. **让 3 次任务失败**
2. **连续 5 次组队失败**
3. **在好人 3 胜后，刺客成功刺杀梅林**

| 角色 | 英文名 | 能力说明 |
|------|--------|----------|
| **莫甘娜** | Morgana | 在派西维尔的视野中，莫甘娜与梅林显示为相同的标记，用以混淆派西维尔的判断。 |
| **刺客** | Assassin | 当善良阵营完成 3 次任务后，刺客可以**指认一名玩家为梅林并发动刺杀**。刺杀成功则坏人直接获胜。 |
| **莫德雷德** | Mordred | 梅林**无法看到**莫德雷德的身份。莫德雷德是隐藏在梅林视野之外的邪恶角色。 |
| **奥伯伦** | Oberon | 其他邪恶玩家的**私有频道中看不到奥伯伦**，奥伯伦也看不到其他坏人。彼此之间互不知晓。 |
| **莫甘娜的爪牙** | Minion | 普通坏人，无特殊能力，但能在坏人频道中看到队友（奥伯伦除外）。 |

### 2.3 角色视野关系图

```
梅林  →  看到所有坏人（除莫德雷德）
派西维尔  →  看到"梅林/莫甘娜"两人（不标明谁是谁）
莫德雷德  →  梅林看不到他
莫甘娜  →  派西维尔看到时与梅林相同
奥伯伦  →  其他坏人看不到他，他也看不到其他坏人
刺客  →  拥有最终刺杀权
```

系统根据玩家人数自动分配角色，默认配置如下：

| 人数 | 善良阵营 | 邪恶阵营 |
|------|----------|----------|
| **5 人** | 梅林 + 派西维尔 + 忠诚的仆人 × 2 | 莫甘娜 + 刺客 |
| **6 人** | 梅林 + 派西维尔 + 忠诚的仆人 × 3 | 莫甘娜 + 刺客 |
| **7 人** | 梅林 + 派西维尔 + 忠诚的仆人 × 2 | 莫甘娜 + 刺客 + 奥伯伦 |
| **8 人** | 梅林 + 派西维尔 + 忠诚的仆人 × 3 | 莫甘娜 + 刺客 + 爪牙 |
| **9 人** | 梅林 + 派西维尔 + 忠诚的仆人 × 4 | 莫甘娜 + 刺客 + 莫德雷德 |
| **10 人** | 梅林 + 派西维尔 + 忠诚的仆人 × 4 | 莫甘娜 + 刺客 + 莫德雷德 + 奥伯伦 |
| **11 人** | 梅林 + 派西维尔 + 忠诚的仆人 × 5 | 莫甘娜 + 刺客 + 莫德雷德 + 奥伯伦 |
| **12 人** | 梅林 + 派西维尔 + 忠诚的仆人 × 6 | 莫甘娜 + 刺客 + 莫德雷德 + 奥伯伦 |

> **阵营比例**：5–6 人（3好 vs. 2坏）；7 人（4好 vs. 3坏）；8–12 人（5–7好 vs. 3–5坏）。

## 四、任务人数配置

每局游戏共进行 **5 轮任务**，每轮任务需要不同人数参与。具体配置如下：

| 玩家人数 | 任务 1 | 任务 2 | 任务 3 | 任务 4 | 任务 5 |
|----------|--------|--------|--------|--------|--------|
| **5 人** | 2 | 3 | 2 | 3 | 3 |
| **6 人** | 2 | 3 | 4 | 3 | 4 |
| **7 人** | 2 | 3 | 3 | 4* | 4 |
| **8 人+** | 3 | 4 | 4 | 5* | 5 |

> **\* 第 4 个任务为特殊任务**：需要 **2 张失败票** 才会导致任务失败，其他任务只需 **1 张失败票** 即失败。

## 五、游戏流程

游戏由系统作为主持人，通过状态机控制完整的任务流程。每一轮包含以下阶段：

### 5.1 准备阶段

1. 所有玩家加入游戏房间。
2. 系统根据人数自动**分配角色**。
3. 系统向每位玩家**私密展示视野信息**（如梅林看到坏人、派西维尔看到梅林/莫甘娜等）。
4. 邪恶阵营玩家被自动加入**私有聊天频道**，可在此秘密讨论策略。

### 5.2 组队阶段

1. 系统指定一位玩家作为当前**队长**（按顺序轮换）。
2. 队长从所有玩家中选择**指定人数**组成任务队伍（人数参考"任务人数配置"表）。
3. 队伍确定后，所有玩家对该组队方案进行**投票**（同意 / 反对）。

### 5.3 组队投票

- **过半数同意**：组队成功，进入"任务执行"阶段。
- **过半数反对**：组队失败，队长传给**下一位**玩家，重新开始组队。
- **连续 5 次组队失败**：邪恶阵营**直接获胜**，游戏结束。

> 投票结果为**公开信息**，所有玩家可看到每个人的投票选择。

### 5.4 任务执行

组队成功后，被选中执行任务的所有玩家**秘密**选择任务结果：

| 阵营 | 可选操作 | 规则 |
|------|----------|------|
| **善良阵营** | 只能选择「成功」 | 好人必须帮助任务成功 |
| **邪恶阵营** | 可选择「成功」或「失败」 | 坏人可以自由选择，决定是否破坏任务 |

- 系统收集所有任务执行者的选择后，**公布任务结果**。
- 判定规则：
  - **普通任务（1、2、3、5 轮）**：出现 **≥1 张失败票** → 任务失败
  - **第 4 轮特殊任务**：出现 **≥2 张失败票** → 任务失败；否则成功

### 5.5 循环进行

重复执行 **5.2 → 5.3 → 5.4** 的流程，直到满足以下任一条件：

| 条件 | 结果 |
|------|------|
| 善良阵营完成 **3 次任务成功** | 进入"刺杀阶段" |
| 邪恶阵营导致 **3 次任务失败** | 邪恶阵营直接获胜，游戏结束 |
| **连续 5 次组队失败** | 邪恶阵营直接获胜，游戏结束 |

### 5.6 刺杀阶段

当善良阵营成功完成 3 次任务后，游戏进入最终阶段：

1. **刺客发动刺杀**：刺客指定一名玩家，声称其为梅林。
2. **判定结果**：
   - 被指认者确实是 **梅林** → **邪恶阵营获胜**
   - 被指认者**不是梅林** → **善良阵营获胜**

> 刺杀阶段是邪恶阵营最后的翻盘机会。梅林在游戏全程中需要尽量隐藏自己的身份，避免暴露线索。

## 六、湖上夫人模式（可选）

湖上夫人（Lady of the Lake）是一个可选的游戏扩展机制，可以在创建房间时启用。

### 6.1 启用条件

- 通过配置参数开启（见第八节）。
- **5/6 人游戏也可以启用**湖上夫人模式。

### 6.2 规则说明

| 项目 | 说明 |
|------|------|
| **触发时机** | 从第 2 轮任务开始 |
| **查验权** | 上一轮任务成功的队伍领袖可以指定一名玩家查验阵营 |
| **查验结果** | 被查验的玩家会看到查验结果（好人 / 坏人） |
| **限制条件** | 不能查验已经查验过的玩家，也不能查验当前的队伍领袖 |

### 6.3 策略价值

湖上夫人提供了一个额外的信息获取渠道，帮助玩家通过验证身份来推理阵营。但由于查验结果仅被查验者自己知道，其他玩家需要通过其后续言行来判断其是否说真话。

## 七、胜负判定总结

### 善良阵营获胜条件（需同时满足）

1. 成功完成 **3 次任务**
2. 刺客**未能刺杀梅林**（或梅林成功隐藏）

### 邪恶阵营获胜条件（满足任一）

1. 导致 **3 次任务失败**
2. **连续 5 次组队失败**
3. 刺客**成功刺杀梅林**

## 八、配置参数

创建游戏房间时，可通过以下参数自定义游戏规则：

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `questDiscussionTime` | 整数 / null | `null` | 组队讨论阶段的限时（单位：秒）。设置为 `0` 或 `null` 表示**不限时**。 |
| `enableLady` / `lakeLady` | 布尔值 | `false` | 是否启用**湖上夫人**扩展模式。 |
| `allowRoleHints` | 布尔值 | `false` | 是否允许系统提供**角色提示**（如向新手解释角色能力）。 |

### 配置示例

```json
{
  "questDiscussionTime": 120,
  "enableLady": true,
  "allowRoleHints": true
}
```

以上配置表示：组队讨论限时 120 秒，启用湖上夫人模式，允许角色提示。

## 九、后端逻辑说明

### 9.1 状态机管理

游戏流程由**状态机**（State Machine）驱动，完整管理以下状态和转换：

```
[准备阶段] → [组队阶段] → [组队投票] → [任务执行] → [结果结算]
                                              ↑_________________________↓
                                   （重复直到分出胜负）
                                                          ↓
                                              [刺杀阶段]（好人3胜后）
```

状态机确保每一步操作都有明确的流转规则，防止非法操作破坏游戏逻辑。

### 9.2 邪恶阵营私有频道

- 游戏开始时，所有邪恶阵营玩家（**奥伯伦除外**）被自动加入私有聊天频道。
- 该频道仅邪恶阵营玩家可见，可用于协调投票策略、讨论如何伪装等。
- 奥伯伦因特性原因**不在此频道中**，需要独自判断和行动。

### 9.3 实时广播机制

- **组队投票结果**：投票结束后，系统实时广播每位玩家的投票选择（同意/反对）。
- **任务执行结果**：任务结束后，系统实时广播任务成败及失败票数量（不公开执行者身份）。
- **阶段切换**：每次状态流转时，系统向所有玩家推送当前阶段提示。

## 十、策略提示

### 善良阵营建议

- **梅林**：利用信息优势引导投票方向，但不要过于明显地暴露自己。记住——你是刺客的目标。
- **派西维尔**：观察"梅林/莫甘娜"两人的言行，判断谁才是真的梅林。尽量与真梅林建立默契配合。
- **忠诚的仆人**：关注投票模式和任务结果，通过逻辑推理找出可疑的坏人。

### 邪恶阵营建议

- **刺客**：全程观察谁最像梅林（信息最丰富、引导性最强的玩家），为最终的刺杀做准备。
- **莫德雷德**：利用梅林看不到你的优势，积极伪装成好人。
- **奥伯伦**：没有队友信息的情况下，参考公开投票和任务结果来判断队友身份。
- **莫甘娜**：尝试扮演梅林的角色来误导派西维尔，让派西维尔以为你是梅林。

## 十一、常见问题（FAQ）

**Q1：奥伯伦能看到其他坏人吗？**  
A：不能。奥伯伦看不到其他坏人，其他坏人也看不到奥伯伦。

**Q2：莫德雷德能被梅林看到吗？**  
A：不能。莫德雷德是梅林视野盲区内的角色。

**Q3：坏人可以选择让任务成功吗？**  
A：可以。坏人可以投"成功"来伪装自己，但需要至少1张失败票（第4轮需2张）才能让任务失败。

**Q4：组队投票是公开的吗？**  
A：是的。每位玩家的投票（同意/反对）都会公开显示。

**Q5：湖上夫人的查验结果可以撒谎吗？**  
A：被查验者知道真实结果，但他选择向其他人说什么完全由自己决定。其他玩家需要判断其是否可信。
