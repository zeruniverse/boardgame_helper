## 1. 游戏概述

狼人杀是一款经典的多人社交推理游戏。本系统实现了完整的狼人杀游戏逻辑，支持以下特性：

- **游戏人数**：支持 6~18 人参与
- **角色分配**：系统随机分配角色，房主无需手动配置
- **自动进程**：系统控制完整的游戏流程，自动推进各阶段
- **夜间行动**：所有角色夜间行动由系统统一管理
- **狼人私聊**：狼人玩家拥有私有聊天频道，可在指定时段内密谋
- **规则支持**：遵循经典狼人杀规则，包含多种角色与特殊机制

## 2. 角色系统

### 2.1 角色列表

| 角色 | 阵营 | 能力类型 |
|------|------|----------|
| 狼人 (Werewolf) | 狼人阵营 | 主动技能 |
| 预言家 (Seer) | 好人阵营 | 主动技能 |
| 女巫 (Witch) | 好人阵营 | 主动技能 |
| 猎人 (Hunter) | 好人阵营 | 被动技能 |
| 守卫 (Guard) | 好人阵营 | 主动技能 |
| 平民 (Villager) | 好人阵营 | 无特殊能力 |

### 2.2 角色能力详解

#### 狼人 (Werewolf)

- **阵营**：狼人阵营
- **技能**：每晚可共同选择一名玩家击杀
- **特殊机制**：
  - 所有狼人共享狼人团队频道，可在频道内协商击杀目标
  - 多名狼人投票一致后，击杀才会生效
  - 狼人频道在游戏全程（白天和夜晚）均可使用

#### 预言家 (Seer)

- **阵营**：好人阵营
- **技能**：每晚可查验一名玩家的阵营归属
- **查验结果**：
  - 狼人 → 显示为"狼人"
  - 其他所有角色（好人阵营）→ 显示为"好人"
- **提示**：预言家无法区分具体的神职角色和平民

#### 女巫 (Witch)

- **阵营**：好人阵营
- **技能**：拥有两瓶药水，每瓶只能使用一次
  - **解药**：夜晚可救活一名被狼人击杀的玩家（需在被狼人杀死后、天亮前使用）
  - **毒药**：夜晚可毒杀一名玩家
- **使用规则**：
  - 两瓶药水在同一晚不可同时使用
  - 解药和毒药各仅有一瓶，用完即永久失去该能力
  - 女巫可以在知晓当晚死亡信息后再决定是否使用解药
  - 女巫不能对自己使用解药（女巫不可自救）

#### 猎人 (Hunter)

- **阵营**：好人阵营
- **技能**：被投票出局或在夜晚死亡时，可以开枪带走一名存活的玩家
- **触发条件**：
  - 白天投票被处决时
  - 夜晚被狼人杀死时
  - 夜晚被女巫毒死时**不能**开枪
- **特殊机制**：猎人开枪带走的目标如果是另一名猎人，可触发猎人开枪链（详见[7.4 猎人开枪链](#74-猎人开枪链)）

#### 守卫 (Guard)

- **阵营**：好人阵营
- **技能**：每晚可选择一名玩家进行守护，使其当晚免受狼人击杀
- **限制规则**：
  - 不能连续两晚守护同一名玩家
  - 守卫可以守护自己
  - 若被守护的玩家同时被女巫使用解药，则该玩家**仍会死亡**（同守同救算死亡）

#### 平民 (Villager)

- **阵营**：好人阵营
- **技能**：无特殊能力
- **作用**：通过白天讨论和投票，协助好人阵营找出并驱逐狼人

## 3. 默认角色配置

系统根据参与人数自动调整角色配置，默认配置如下：

| 人数范围 | 狼人 | 预言家 | 女巫 | 猎人 | 守卫 | 平民 |
|----------|------|--------|------|------|------|------|
| 6~7 人 | 2 | 1 | 1 | 0 | 0 | 补齐剩余 |
| 8~11 人 | 3 | 1 | 1 | 1 | 0~1 | 补齐剩余 |
| 12 人及以上 | 4 | 1 | 1 | 1 | 1 | 补齐剩余 |

> **说明**：平民数量 = 总人数 - 狼人 - 预言家 - 女巫 - 猎人 - 守卫。当 `allowCustomRoles` 开启时，房主可自定义角色配置。

### 角色配置示例

- **6 人局**：2 狼 + 1 预言家 + 1 女巫 + 2 平民
- **9 人局**：3 狼 + 1 预言家 + 1 女巫 + 1 猎人 + 3 平民
- **12 人局**：4 狼 + 1 预言家 + 1 女巫 + 1 猎人 + 1 守卫 + 4 平民

## 4. 游戏流程

### 4.1 流程概览

```
准备阶段 → 首夜（狼人→预言家→女巫→守卫） → 第一天白天（公布死亡→讨论+投票） → 
夜晚（狼人→预言家→女巫→守卫） → 白天（公布死亡→讨论→投票） → 
重复"夜晚→白天"循环直到游戏结束
```

### 4.2 各阶段详解

#### 阶段一：准备阶段

1. 房主点击"开始游戏"
2. 系统根据当前人数，按照默认角色配置（或自定义配置）随机分配角色
3. 所有玩家收到自己的角色信息
4. 游戏自动进入首夜

#### 阶段二：首夜

- **流程**：
  1. 系统提示狼人睁眼
  2. 狼人玩家在狼人频道中互相确认队友身份
  3. 狼人共同选择一名玩家进行击杀（可空刀）
  4. 预言家、女巫、守卫等神职依次行动
  5. 所有角色闭眼，进入第一天白天

> **设计意图**：首夜即完整的游戏夜晚，让各角色从一开始就投入游戏。

#### 阶段三：白天阶段

白天是公开讨论和投票的核心阶段，流程如下：

1. **公布死亡信息**
   - 系统公布昨晚的死亡情况（死亡玩家编号/昵称）
   - 若无死亡，则公布"昨晚是平安夜"

2. **遗言阶段（被处决者遗言）**
   - 若白天投票产生了处决者，该玩家发表遗言
   - 若处决者是猎人，遗言后触发开枪

3. **自由讨论**
   - 所有存活玩家可自由发言
   - 讨论时间由 `dayTime` 配置控制

4. **投票处决**
   - 存活玩家投票选出怀疑的目标
   - 警长的放逐票按 **1.5 票**计算，其余玩家按 1 票计算
   - 得票最多的玩家被处决
   - 首次平票时，平票玩家进入一次 PK 发言；PK 台玩家本轮不能投票，其他存活玩家只能在 PK 台玩家中选择
   - PK 再次平票时，当天无人被放逐并进入夜晚

5. **处决者遗言**
   - 被处决的玩家发表遗言

6. **猎人开枪**
   - 若被处决者是猎人，触发开枪技能，选择一名玩家带走

7. **胜负判定**
   - 检查是否满足胜负条件
   - 若游戏未结束，进入夜晚阶段

#### 阶段四：夜晚阶段

夜晚是各角色执行秘密行动的回合，按固定顺序进行：

| 顺序 | 角色 | 行动内容 |
|------|------|----------|
| 1 | 狼人 | 在狼人频道协商，共同选择一名玩家击杀 |
| 2 | 预言家 | 选择一名玩家查验阵营 |
| 3 | 女巫 | 根据死亡信息决定是否使用解药或毒药 |
| 4 | 守卫 | 选择一名玩家进行守护（不能连续守护同一人） |

夜晚结束后，系统结算所有行动效果，天亮后公布死亡信息。

---

## 5. 胜负判定

游戏在每轮白天投票结束后和每次死亡事件后进行胜负判定。

### 好人胜利条件

- **所有狼人死亡**
- 即狼人阵营存活人数为 0

### 狼人胜利条件

- **好人数量 <= 狼人数量**
- 即狼人阵营人数大于或等于好人阵营存活人数
- 狼人可通过"屠边"或"屠城"策略实现胜利

### 平局/特殊判定

- 若同时满足双方胜利条件（极少数特殊情况），由系统根据具体逻辑处理
- 所有角色出局后游戏结束，按最终阵营判定胜负

## 6. 配置参数

游戏支持以下配置参数，房主可在创建房间时设置：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `dayTime` | 整数/Null | `null` | 白天讨论和投票阶段的时间限制（秒）。`0` 或 `null` 表示不限时 |
| `nightTime` | 整数/Null | `null` | 夜晚各角色行动阶段的时间限制（秒）。`0` 或 `null` 表示不限时 |
| `voteTime` | 整数/Null | `null` | 投票阶段的独立时间限制（秒）。`0` 或 `null` 表示不限时 |
| `allowCustomRoles` | 布尔值 | `false` | 是否允许房主自定义角色配置。`true` 开启自定义角色；`false` 使用系统默认配置 |

### 参数使用示例

```json
{
  "dayTime": 300,
  "nightTime": 60,
  "voteTime": 30,
  "allowCustomRoles": false
}
```

> 上述配置表示：白天讨论 5 分钟，夜晚行动每阶段 60 秒，投票 30 秒，使用默认角色配置。

## 7. 特殊机制

### 7.1 警长机制

- **竞选时机**：首个白天在公布夜间死亡结果前进行警长竞选。
- **警上/警下**：选择“上警”的玩家成为候选人并依次发言；选择“不上警”的玩家为“警下”玩家，只有警下玩家拥有警长竞选投票权。
- **当选规则**：只有一名候选人时直接当选；多名候选人由警下玩家投票，最高票者当选。
- **竞选平票**：首次平票时，平票候选人进行一次 PK 发言并由原警下玩家重新投票；再次平票则警徽流失，本局不设警长。
- **放逐票权**：警长在白天放逐投票中拥有 **1.5 票**。
- **警徽传递**：警长死亡时可以把警徽传给另一名存活玩家，也可以撕毁警徽。

### 7.2 狼人频道

- **功能**：狼人玩家专属的私有聊天频道
- **使用时段**：
  - 夜晚行动阶段：狼人可在频道内协商击杀目标
  - 白天讨论阶段：狼人可继续通过频道秘密沟通
- **可见性**：仅狼人阵营玩家可见，好人阵营玩家无法看到频道内容
- **用途**：协调击杀策略、讨论伪装方案、传递虚假信息

### 7.3 遗言机制

- **遗言触发条件**：
  - 白天被投票处决的玩家：**有遗言**
  - 夜晚被狼人杀死的玩家：**无遗言**（默认配置）
  - 被女巫毒死的玩家：**无遗言**
  - 被猎人开枪带走的玩家：**无遗言**
- **遗言内容**：死亡玩家可在限定时间内发表最后陈述
- **遗言可见性**：所有存活玩家均可看到遗言内容

> **提示**：遗言机制的具体规则（如夜晚死亡是否可留遗言）可通过配置调整。

### 7.4 猎人开枪链

当猎人开枪带走的目标也是猎人时，可能触发连锁反应：

- **机制描述**：
  1. 猎人 A 死亡，开枪带走猎人 B
  2. 猎人 B 死亡，触发开枪技能，继续带走另一名玩家
  3. 若猎人 B 带走的目标也是猎人，连锁继续
- **防死循环措施**：
  - 系统设置**递归深度限制**，防止无限连锁
  - 达到深度上限后，连锁自动终止
- **使用毒药限制**：被女巫毒死的猎人**不能**开枪

### 7.5 连续守护限制

守卫的技能受到以下限制：

- **核心规则**：守卫不能连续两晚守护同一名玩家
- **可以自守**：守卫可以选择守护自己
- **同守同救冲突**：
  - 若某玩家当晚被狼人击杀
  - 同时被守卫守护且被女巫使用解药
  - 则该玩家**仍会死亡**（"同守同救死"规则）
- **状态追踪**：系统记录每晚的守护目标，确保不违反连续守护限制

### 7.6 多死亡处理

夜晚可能同时发生多起死亡事件：

- **多死亡场景**：
  - 狼人击杀一名玩家
  - 女巫使用毒药毒杀另一名玩家
  - 同守同救导致额外死亡
- **处理流程**：
  1. 天亮后一次性公布所有死亡信息
  2. 按顺序处理每位死亡玩家的遗言和猎人连锁
  3. 每处理完一位，检查游戏是否结束
  4. 所有死亡处理完毕后，进入白天讨论阶段

## 8. 后端逻辑说明

### 8.1 状态机管理

游戏采用**状态机模式**管理游戏阶段，确保流程有序推进：

```
[准备] → [首夜] → [白天讨论] → [投票] → [夜晚] → [白天讨论] → ... → [游戏结束]
```

- 每个游戏阶段对应一个独立的状态节点
- 状态转移由系统自动控制，满足条件后自动推进
- 每个状态节点定义了：
  - 该阶段允许的玩家操作
  - 阶段超时时间
  - 阶段结束条件
  - 下一阶段跳转逻辑

### 8.2 超时处理

当配置了时间限制时，系统提供自动超时处理机制：

- **超时触发**：当前阶段倒计时结束时，自动推进到下一阶段
- **超时默认值**：
  - 若 `dayTime`、`nightTime`、`voteTime` 设置为 `0` 或 `null`，该阶段不限时
  - 限时阶段需至少有一名玩家完成操作才推进，或等待超时
- **超时安全机制**：
  - 若所有玩家提前完成操作，可自动跳过等待时间
  - 超时处理确保游戏不会因为玩家离线或操作延迟而卡住

### 8.3 断线重连

系统支持玩家断线重连功能：

- **重连恢复内容**：
  - 当前游戏阶段和状态
  - 玩家自身的角色信息
  - 之前的公开聊天记录
  - 之前的发言记录（包括白天讨论内容）
- **重连限制**：
  - 无法恢复离线期间的夜间私密信息（如查验结果需等待下一次行动）
  - 狼人频道历史记录根据安全策略决定是否展示
- **实现方式**：服务器保存完整的游戏状态快照，玩家重连时同步状态数据
