# 一夜终极狼人（One Night Ultimate Werewolf）规则与实现说明

本文档描述 `boardgame_helper` 当前实现的一夜终极狼人规则。本实现以仓库中的 `one_night_ref/README.md` 为权威参考，角色配置、夜间行动顺序与胜负判定均按该参考实现执行。

## 1. 基本人数与发牌

- 支持人数：3-10 人。
- 每局使用的角色牌数量固定为：玩家人数 + 3。
- 每名玩家获得 1 张角色牌，其余 3 张为中心牌。
- 夜间行动可能改变玩家的当前身份；最终胜负以夜晚全部行动结束后的当前身份为准。

## 2. 可用角色与阵营

### 狼人阵营

| 角色 | 规则摘要 |
| --- | --- |
| 普通狼人 | 夜晚与其他初始狼人互相认识；若自己是唯一初始狼人，可以查看 1 张中心牌。 |
| 头狼 | 与其他初始狼人互相认识，并选择 1 名玩家变成普通狼人。 |
| 狼先知 | 与其他初始狼人互相认识，并查看 1 名其他玩家的角色。 |
| 爪牙 | 查看初始狼人是谁；爪牙属于狼人阵营，但自身不是狼人。 |

### 好人阵营

| 角色 | 规则摘要 |
| --- | --- |
| 预言家 | 查看 1 名其他玩家的角色。 |
| 学徒预言家 | 查看 1 张中心牌。 |
| 女巫 | 查看 1 张中心牌，并将该中心牌交给 1 名玩家。 |
| 揭示者 | 选择 1 名其他玩家；若该玩家当前不是狼人且不是皮匠，则公开揭示其角色，否则盖回。 |
| 强盗 | 与 1 名其他玩家交换角色牌，并查看自己的新角色。 |
| 捣蛋鬼 | 交换另外 2 名玩家的角色牌。 |
| 失眠者 | 夜晚结束时查看自己的当前角色。 |
| 酒鬼 | 将自己的角色牌与 1 张中心牌交换，且不查看新角色。 |
| 守夜人 | 查看是否存在其他初始守夜人。 |
| 村民 | 没有夜间技能。 |

### 第三方阵营

| 角色 | 规则摘要 |
| --- | --- |
| 皮匠 | 只有自己成为唯一得票最多的玩家并被处决时获胜。 |

## 3. 配置数量限制

- 守夜人必须配置为 **0 个或 2 个**；配置为 1 个或超过 2 个均为非法配置。
- 皮匠最多只能配置 **1 个**。
- 除普通狼人、村民外，其他可用角色最多配置 1 个。
- 配置总牌数必须等于玩家数 + 3。
- 当前实现只开放本文档列出的参考角色；猎人、化身、哨兵、皮匠学徒等扩展角色不属于本参考规则集，不能作为本模式配置使用。

## 4. 夜间行动顺序

夜间阶段严格按以下顺序行动：

1. 所有狼人
2. 头狼
3. 狼先知
4. 爪牙
5. 守夜人
6. 预言家
7. 学徒预言家
8. 强盗
9. 女巫
10. 捣蛋鬼
11. 酒鬼
12. 失眠者
13. 揭示者

无夜间主动技能的村民、皮匠不会进入夜间行动队列。

## 5. 白天讨论与投票

- 夜晚结束后进入白天讨论。
- 每名玩家必须投 1 票，可投给另一名玩家，也可投给墓地（中心牌）。
- 若墓地得票数不低于任一玩家的最高得票数，则无人被处决。
- 若玩家最高得票至少为 2 且高于墓地票数，则所有并列最高票玩家都会被处决；若所有玩家最高票只有 1 票，则无人被处决。

## 6. 胜负判定

胜负判定只看夜间行动结束后的当前身份：

1. 若任意真实狼人被处决：好人阵营获胜；若皮匠同时死亡，皮匠玩家个人也达成自己的胜利条件。
2. 若没有真实狼人死亡但皮匠被处决：皮匠获胜，狼人阵营不能因皮匠死亡获胜。
3. 若当前场上没有真实狼人：
   - 无人被处决时，好人阵营获胜；
   - 有爪牙且被处决者中存在非爪牙、非皮匠玩家时，爪牙按狼人阵营获胜；
   - 没有爪牙且误杀了好人时，没有阵营获胜。
4. 其他情况下，场上至少仍有真实狼人且没有真实狼人死亡，狼人阵营获胜。

> 说明：胜负按夜晚行动结束后的当前身份结算；皮匠只要被处决就个人获胜，但不会让狼人阵营一并获胜。

## 7. 实现一致性要点

- 用户可见角色名称统一为“守夜人”和“皮匠”；内部枚举保留原有英文标识，不影响玩家展示。
- 头狼不会额外添加第 4 张中心牌；头狼行动会把所选玩家的当前身份直接变成普通狼人。
- 爪牙、守夜人等需要识别夜晚开始时身份的角色，以初始身份为依据；胜负判定以最终当前身份为依据。
- 前后端配置校验、预设阵容和文档应保持一致，避免出现前端可选但后端拒绝、或文档描述与实际逻辑不一致的情况。
