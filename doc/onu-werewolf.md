## 1. 游戏概述

**一夜终极狼人** 是一款快节奏的社交推理类桌游，由系统（主持人）自动控制游戏进程。

| 项目 | 说明 |
|------|------|
| **游戏人数** | 3 ~ 10 人 |
| **游戏时长** | 单轮游戏，仅需一个夜晚和一个白天 |
| **游戏模式** | 系统分配角色并控制夜间行动顺序 |
| **核心机制** | 白天讨论后投票，被投票出局的玩家或其死亡目标可能导致胜负变化 |

游戏的核心在于：**你的初始角色可能在夜间被交换，最终决定胜负的是你的最终角色，而非初始角色**。因此，即使你开始时是好人，一觉醒来你也可能变成了狼人。

## 2. 角色系统与夜间行动顺序

夜间行动严格按照以下顺序执行，每个角色被系统依次"唤醒"并执行技能。

### 2.1 夜间行动角色

按以下顺序执行：

| 顺序 | 角色 | 人数 | 技能说明 |
|:----:|------|:----:|----------|
| 1 | **化身 (Doppelganger)** | 0~1 | 复制一名其他玩家的角色，继承该角色的技能和阵营 |
| 2 | **狼人 (Werewolf)** | 2 | 查看彼此身份（如果只有1个狼人，则查看中间1张牌） |
| 3 | **爪牙 (Minion)** | 0~1 | 查看狼人身份，知道谁是狼人 |
| 4 | **共济会 (Mason)** | **0 或 2** | 确认彼此身份，知道另一名共济会成员是谁（**必须成对出现**） |
| 5 | **预言家 (Seer)** | 1 | 查看另一名玩家的牌，或查看中间2张牌 |
| 6 | **强盗 (Robber)** | 1 | 与另一名玩家交换牌，并查看自己的新牌 |
| 7 | **捣蛋鬼 (Troublemaker)** | 1 | 交换另外两名玩家的牌（**不看**交换后的牌） |
| 8 | **酒鬼 (Drunk)** | 1 | 与中间1张牌交换（**不看**自己的新牌） |
| 9 | **失眠者 (Insomniac)** | 1 | 查看自己的最终牌（经过所有交换后的牌） |

> **注意**：
> - 化身（如有）最先行动，复制其他角色后立即执行该角色的技能（部分角色如揭示者、馆长需在原角色之后再次行动）。
> - 狼人在爪牙和共济会之前行动；如果场上只有1个狼人，该狼人可以**自选**查看3张中间牌中的1张。
> - **共济会（石匠）必须成对出现（0个或2个）**，不能配置1个或超过2个石匠。
> - 共济会在预言家之前行动，确认彼此身份。
> - 捣蛋鬼交换牌后**不能查看**交换后的牌，因此无法确定那两名玩家现在的身份。
> - 酒鬼交换后**不能查看**自己的新牌，所以连自己最终是什么都不知道。
> - 失眠者是最后行动的，可以看到经过所有交换后自己最终的牌。

### 2.2 纯白天角色

以下角色在夜间**不执行任何行动**，仅在白天讨论和投票阶段发挥作用：

| 角色 | 技能说明 |
|------|----------|
| **猎人 (Hunter)** | 被投票出局时，其投票目标也一同死亡 |
| **皮匠 (Tanner)** | 被投票出局时，**单独胜利**（无论其他结果） |
| **村民 (Villager)** | 无特殊能力，属于好人阵营 |

> **注意**：
> - 猎人被投出时，其投票目标会一起死亡，这可能导致额外的胜负变化。
> - 皮匠的目标就是**被投票出局**，成功即单独获胜。

## 3. 默认角色配置

系统根据玩家人数自动配置角色，**实际配置为 玩家人数 + 3张中间牌**。

| 玩家人数 | 角色配置（共 人数+3 个） |
|:--------:|----------|
| 3人 | 2狼 + 预言家 + 强盗 + 捣蛋鬼 + 村民 |
| 4人 | 2狼 + 预言家 + 强盗 + 捣蛋鬼 + 2村民 |
| 5人 | 2狼 + 预言家 + 强盗 + 捣蛋鬼 + 3村民 |
| 6人 | 2狼 + 预言家 + 强盗 + 捣蛋鬼 + 酒鬼 + 失眠者 + 村民 |
| 7人 | 2狼 + 爪牙 + 预言家 + 强盗 + 捣蛋鬼 + 酒鬼 + 失眠者 + 村民 |
| 8人 | 2狼 + 爪牙 + 预言家 + 强盗 + 捣蛋鬼 + 酒鬼 + 失眠者 + 猎人 + 村民 |
| 9人 | 2狼 + 爪牙 + 预言家 + 强盗 + 捣蛋鬼 + 酒鬼 + 失眠者 + 猎人 + 皮匠 + 村民 |
| 10人 | 2狼 + 爪牙 + 预言家 + 强盗 + 捣蛋鬼 + 酒鬼 + 失眠者 + 猎人 + 皮匠 + 共济会×2 |

> **说明**：
> - 中间始终保留 **3张牌** 作为"底牌"。
> - 酒鬼会与中间牌交换，因此底牌中可能包含场上玩家的原牌。
> - 配置可根据需求自定义调整（详见 [配置参数](#6-配置参数)）。

## 4. 游戏流程

游戏分为五个阶段，依次进行：

```
准备阶段 → 夜晚阶段 → 白天阶段 → 投票阶段 → 结算阶段
```

### 4.1 准备阶段

1. **房主可以在游戏开始前配置本局游戏的角色**（仅等待阶段可操作）。
   - 从可用角色列表中选择本局要使用的角色。
   - 角色总数必须等于 **玩家人数 + 3张中间牌**。
   - **石匠角色必须成对出现**：只能选择 0 个或 2 个石匠，不能选择 1 个。
2. 系统根据当前人数自动分配角色配置（或使用自定义配置）。
3. 系统将角色牌随机分配给每位玩家，同时预留 **3张中间牌**。
4. 每位玩家只能看到自己的**初始角色**。
5. 准备阶段结束后，自动进入夜晚阶段。

### 4.2 夜晚阶段

1. 系统按照 [夜间行动顺序](#21-夜间行动角色) 依次唤醒各角色。
2. 被唤醒的角色执行相应的夜间技能（查看身份、交换牌等）。
3. 所有夜间技能执行完毕后，自动进入白天阶段。

> **时间规则**：
> - 每位玩家的夜间行动限时完成（可配置）。
> - 所有技能处理完成后，系统延迟 **2秒** 自动结束夜晚阶段。

### 4.3 白天阶段

1. 所有玩家"睁眼"，开始讨论。
2. 玩家根据夜间获得的信息（或缺乏信息），分析谁可能是狼人。
3. 玩家可以互相质疑、撒谎、推理，试图找出狼人。

> **讨论时间**：
> - 支持**限时讨论**（默认配置，单位为秒）。
> - 支持**不限时讨论**（`discussTime` 设为 0 或 null）。
> - 时间到后自动进入投票阶段。

### 4.4 投票阶段

1. 每位玩家投票给一名自己认为是狼人的玩家。
2. **可以投票给自己**。
3. 所有玩家投票完成后，进入结算阶段。

### 4.5 结算阶段

1. 统计所有投票，**得票最多的玩家出局**。
2. 如果出现**平票**，则**所有平票者全部出局**。
3. 被投票出局的玩家揭示**最终角色**（注意：是最终角色，不是初始角色）。
4. 触发相关效果：
   - 若出局者是**猎人**：其投票目标也一同死亡。
   - 若出局者是**皮匠**：皮匠单独胜利。
5. 根据最终结果判定胜负。

## 5. 胜负判定

胜负判定基于**最终角色**（经过夜间交换后的角色），而非初始角色。

| 胜利阵营 | 判定条件 |
|----------|----------|
| **好人胜利** | 没有人被投票出局 **或** 被投票出局的是狼人 |
| **狼人胜利** | 被投票出局的是村民/预言家/强盗等非狼人角色 |
| **皮匠胜利** | 皮匠被投票出局（**皮匠胜利优先级最高**，无论其他结果） |

### 胜负判定详细说明

- **无人被投出**：好人阵营胜利。
- **投出狼人**：好人阵营胜利。
- **投出非狼人（村民、预言家、强盗等）**：狼人阵营胜利。
- **投出皮匠**：皮匠单独胜利（优先于好人/狼人胜利）。
- **投出猎人**：猎人死亡后带走其投票目标，然后根据实际死亡玩家的最终角色重新判定胜负。

> **重要提示**：
> - 即使你的初始角色是好人，经过夜间交换后你可能变成了狼人，此时你的胜利条件也会改变。
> - 皮匠的胜利条件优先级最高，只要皮匠被投出，皮匠即获胜。

## 6. 配置参数

游戏支持以下配置参数：

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|:------:|------|
| `discussTime` | `number \| null` | `null` | 白天讨论时间（秒）。`0` 或 `null` 表示不限时 |
| `allowRoleReveal` | `boolean` | `true` | 游戏结束后是否揭示所有玩家的最终角色 |
| `roles` | `Role[]` | 按人数默认 | 角色列表配置，可自定义每局使用的角色 |
| `random` | `boolean` | `true` | 是否随机发牌。`false` 时可手动指定角色分配 |

### 配置示例

```json
{
  "discussTime": 180,
  "allowRoleReveal": true,
  "roles": ["werewolf", "werewolf", "seer", "robber", "troublemaker", "drunk", "insomniac"],
  "random": true
}
```

> 以上配置表示：3分钟讨论时间，结束后揭示角色，使用自定义角色列表，随机发牌。

## 7. 后端逻辑说明

### 7.1 夜间技能处理队列

- 系统将所有夜间技能按**固定顺序**加入处理队列。
- 每个技能处理完毕后，**自动进入下一个**技能。
- 所有技能处理完成后，系统**自动进入白天阶段**。

### 7.2 不限时模式处理

在不限时模式下：

1. 技能按固定顺序依次处理。
2. 每个技能等待玩家操作完成。
3. 所有技能完成后，系统**延迟 2 秒**自动结束夜晚阶段。
4. 进入白天讨论阶段。

### 7.3 投票结算逻辑

1. 收集所有玩家的投票。
2. 统计每位被投票玩家的得票数。
3. 找出得票最多的玩家：
   - 唯一最高 → 该玩家出局。
   - 多人平票 → 所有平票者同时出局。
4. 对每位出局玩家，根据其**最终角色**触发相应效果：
   - 猎人 → 其投票目标也出局。
   - 皮匠 → 皮匠单独胜利。
5. 根据所有出局玩家的最终角色判定胜负。

### 7.4 角色交换追踪

- 系统在整个游戏过程中**持续追踪每张牌的流动**。
- 所有交换操作（强盗、捣蛋鬼、酒鬼）都会被记录。
- 结算时使用的永远是**最终角色**，而非初始角色。
