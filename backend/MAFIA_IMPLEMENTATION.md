# 杀人游戏(Mafia)实现说明

## 概述
基于原有的桌游助手项目中的`mafia.ex`文件，在新的TypeScript后端框架中完整实现了杀人游戏逻辑。

## 核心文件
- `backend/src/workers/mafiaWorker.ts` - 杀人游戏主要逻辑实现
- `backend/config.json` - 游戏配置（已更新）

## 游戏配置
```json
{
  "speakTime": 60,      // 发言时间（秒）
  "actionTime": 60,     // 行动时间（秒）  
  "nightTime": 60,      // 夜晚时间（秒）
  "lastWordRound": 3    // 遗言轮数
}
```

## 支持的游戏状态
- `WAITING` - 等待开始
- `NIGHT` - 夜晚（杀手杀人，警察验人）
- `SPEAK` - 发言阶段
- `VOTE` - 投票阶段
- `PK` - PK阶段（平票后的决胜发言）
- `LAST_WORD` - 夜晚死者遗言
- `LAST_WORD_DAYTIME` - 白天被驱逐者遗言
- `OVER` - 游戏结束

## 角色系统
### 角色类型
- `KILLER` - 杀手（红方）
- `COP` - 警察（蓝方）
- `CIVILIAN` - 平民（蓝方）

### 人数配置
支持8-16人游戏，具体配置：
- 8人: [2杀手, 2警察, 4平民]
- 9人: [2杀手, 2警察, 5平民]
- 10人: [2杀手, 2警察, 6平民]
- 11人: [3杀手, 3警察, 5平民]
- 12人: [3杀手, 3警察, 6平民]
- 13人: [3杀手, 3警察, 7平民]
- 14人: [3杀手, 3警察, 8平民]
- 15人: [4杀手, 4警察, 7平民]
- 16人: [4杀手, 4警察, 8平民]

## 核心功能

### 游戏流程控制
- ✅ 房间准备和游戏开始
- ✅ 角色分配和身份信息管理
- ✅ 游戏状态流转
- ✅ 超时处理机制

### 夜晚阶段
- ✅ 杀手协商杀人
- ✅ 警察验人
- ✅ 离线玩家处理
- ✅ 平安夜检测

### 白天阶段
- ✅ 死者遗言
- ✅ 轮流发言
- ✅ 投票驱逐
- ✅ 平票PK机制

### 特殊功能
- ✅ 杀手自爆
- ✅ 被驱逐者遗言
- ✅ 系统代投（超时处理）
- ✅ 游戏结束判断

### 胜利条件
- 蓝方（警察、平民）获胜：所有杀手被消灭
- 红方（杀手）获胜：
  - 杀手数量 ≥ 警察数量 + 平民数量
  - 或警察全部被消灭
  - 或平民全部被消灭

- 完全的游戏状态管理

- 步骤计数器和超时控制

### 消息系统

- 单播私人消息

### 离线处理
- 离线玩家自动跳过
- 在线玩家重连同步
- 系统代理操作

## API接口

### 游戏动作
- `ready/unready` - 准备/取消准备
- `start_game` - 开始游戏（房主专用）
- `inspect_suspect` - 警察验人
- `kill_person` - 杀手杀人
- `end_speak` - 结束发言
- `end_last_word` - 结束遗言
- `vote` - 投票
- `confess` - 杀手自爆
- `chat_message` - 聊天消息
- `heartbeat` - 心跳保活

### 事件通知
- `game_started` - 游戏开始
- `role_assigned` - 角色分配
- `night_start` - 夜晚开始
- `day_start` - 白天开始
- `vote_start` - 投票开始
- `game_over` - 游戏结束
- `inspect_result` - 验人结果
- `kill_result` - 杀人结果
